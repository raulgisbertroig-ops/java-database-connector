# Java File I/O and Serialization

A collection of Java exercises focused on file handling, random access files and object serialization.

These exercises were developed as part of my DAM programming coursework to practice Java I/O and resource management.

## 🚀 Topics covered

- File writing with `FileWriter`
- Buffered writing with `BufferedWriter`
- Try-with-resources
- Random access with `RandomAccessFile`
- File positioning with `seek()`
- Java object serialization
- `Serializable`
- `serialVersionUID`
- `transient`
- Exception handling with `IOException`

## 📂 Exercises

### Ticket 1 — Buffered file writing

Uses `FileWriter` and `BufferedWriter` to append messages to a text file.

### Ticket 2 — Random access file

Uses `RandomAccessFile` and `seek()` to locate a record based on a calculated file position.

### Ticket 3 — Object serialization

Implements `Serializable` and demonstrates the use of `serialVersionUID` and `transient`.

## 🎯 Learning objectives

The main goal of this project was to understand:

- Java file handling
- Resource management
- Random file access
- Basic serialization
- Exception handling
